# Project Overview — iVector Lab Website

## 1. Context

iVector Lab is associated with the Department of Computer Science and Information Engineering (CSIE), National Dong Hwa University (NDHU), Hualien, Taiwan.

The website is intended to serve as a public academic portal for the laboratory.

## 2. Product Concept

The website combines:
- A clear academic information architecture.
- Minimal editorial layouts.
- A warm pastel visual system.
- Subtle pixel-art illustrations.
- A single interactive Virtual Lab environment.

The ordinary content pages should prioritize clarity and credibility. The Virtual Lab provides a more playful way to explore the same academic content.

## 3. Design Balance

Target design balance:
- Approximately 70% minimalist academic presentation.
- Approximately 30% subtle pixel-art influence.

This is a qualitative design direction, not a measurable implementation ratio.

## 4. Intended Audience

Visitors may include prospective students, current students, researchers, faculty members, collaborators, and general visitors.

The content should be understandable to a broad academic audience. Technical terminology may be used where appropriate, but research descriptions should remain concise.

## 5. Product Principles

1. Accuracy over volume: do not fill missing information with generated claims.
2. Clarity over decoration: make academic content easy to scan.
3. Consistency: maintain one visual language across pages.
4. Accessibility: support different devices and input methods.
5. Maintainability: keep content and presentation reasonably separate.
6. Restraint: use pixel art as an accent, not as a replacement for academic communication.

## 6. Primary Pages

- Home: overview and selected content.
- About: identity, philosophy, and environment.
- Research: research directions.
- Projects: project directory.
- People: laboratory members.
- Publications: academic output.
- Virtual Lab: interactive navigation scene.

## 7. Reference Baseline

The approved iVector Lab Figma design is the primary visual reference. See the [PRD](PRD.md#1-product-overview) for reference availability. The documented visual direction includes warm ivory backgrounds, pastel accents, Pixelify Sans titles, Plus Jakarta Sans body copy, restrained borders, whitespace, and pixel-art imagery.

If the Figma design and an approved written requirement conflict, document the conflict and ask for clarification rather than silently changing the product.
